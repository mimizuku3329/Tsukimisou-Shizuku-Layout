# 月見草・雫配列

月見草・雫配列は、「ゃ」「ゅ」「ょ」「ぃ」「ぇ」の5キーを**後置きシフト**として使う、月見草系のかな新配列です。

「月見草エキス」をもとに、**10列 × 3行の30キー範囲・オーソリニア配列**を前提として、記憶負荷を下げ目に調整しました。「月見草エキス」から一滴いただいた、という意味で「月見草・雫」と名付けています。

Google日本語入力のローマ字テーブルで実装でき、文字入力に親指キーや同時押しを使いません。

## 特徴

 ### 月見草式シフトキー
 「ゃゅょぃぇ」に繋がるかなでは、「し → ゃ」で「しゃ」のようにそのまま入力します。繋がらないかなでは、5つのキーを別のかなへのシフトキーとして扱います。
 (月見草式というよりは月見草エキス式が正しいかもしれませんが……)
 
 ### 30キー範囲の格子配列を前提に設計
 コンパクトな自作キーボードで使うことを想定し、10列 × 3行に収めました。
 ロウスタッガード前提ではないため左右で押しやすさを区別していません。
 カラムスタッガードでも使用可能です。
 
 ### 清音・濁音・半濁音は別置き
 清音、濁音、半濁音はそれぞれ前後に繋がりやすいかなが違います。そのため、別のかなとしてそれぞれの連接を考え、打ちやすい位置に配置しています。
 
 ### 拗音・外来音を覚えやすく
 マイナーな拗音を3打とする代わりに、外来音の対応範囲を広げ、ほぼすべての外来音を同じ規則で入力できるようにしました。
 
 ### Google日本語入力だけで実装可能
 専用の配列変換ソフトを必要とせず、Google日本語入力というIMEでの実装であるため安定した動作を期待できます。

## 配列図の読み方

それぞれのキーの**左上のマスが、そのキーを単打したときのかな**です。残りのマスは、そのキーの後に「ゃ」「ゅ」「ょ」「ぃ」「ぇ」を押したときの割り当てを示します。

![月見草・雫配列の配列図。各キーの左上が単打で、残りの5か所が後置きシフトの割り当て](https://github.com/user-attachments/assets/ac398d5d-77f0-41ae-a537-2594b2674757)
たとえば「か」のキーは、次の割り当てです。
| 入力するキー | 出力 |
| --- | --- |
| か | か |
| か → ゃ | あ |
| か → ゅ | ご |
| か → ょ | さ |
| か → ぃ | も |
| か → ぇ | や |

図の色には、次の意味があります。
| 色 | 意味 |
| --- | --- |
| 青色 | 「し」など、後ろに小書きのかなを付けて拗音・外来音を入力するかな |
| 緑色 | 「り」など、拗音・外来音の省略入力ができるかな |
| 黄色 | 後置きシフトに使う「ゃ」「ゅ」「ょ」「ぃ」「ぇ」のキー |

## 入力ルールと入力例

以下の「→」は、**キーを順番に押すこと**を示します。同時押しではありません。入力キーは、配列図の左上に書かれた単打のかなで表しています。

### 後置きシフト

「ゃゅょぃぇ」に繋がらないかなの後に、これらのキーを押すと、別のかなに変わります。

| 入力するキー | 出力 |
| --- | --- |
| か → ゃ | あ |
| か → ゅ | ご |

### 拗音・外来音

「し」などの背景が青色のかなは、小書きのかな繋がります。この場合は別のかなへのシフトにはならず、「し」に「ゃ」を付けた「しゃ」のように入力できます。
| 入力するキー | 出力 |
| --- | --- |
| し → ゃ | しゃ |

また、「つ」や「と」などの「ゃゅょ」に繋がらず「ぁぅぉ」に繋がるかなでは「ゃゅょ」が「ぁぅぉ」に自動で変換されます。
| 入力するキー | 出力 |
| --- | --- |
| つ → ゃ | つぁ |
| と → ゅ | とぅ |

小書きの「ゎ」は単体のかなとして「の→ゅ」で入力できます。

### 拗音・外来音の省略入力

「り」などの背景が緑色のかなは、拗音・外来音を入力するときに、途中のシフトを省略できます。

たとえば「り」は「が → ぃ」で入力します。「りゃ」を入力するときは、通常の「が → ぃ → ゃ」の3打に加えて、「が → ゃ」の2打でも入力することができます。

| 入力するキー | 出力 | 打数 |
| --- | --- | --- |
| が → ぃ | り | 2打 |
| が → ぃ → ゃ | りゃ | 3打 |
| が → ゃ | りゃ | 2打(省略入力) |

### 小書きの母音を後ろに付ける

このシフト方式では、「はぁ」「とぉ」などのかなの後に小書きの母音が続く場合の入力ができません。

代わりに、かなの後に「・」を押すと、そのかなの母音を小書きで追加できます。

| 入力するキー | 出力 |
| --- | --- |
| は → ・ | はぁ |
| と → ・ | とぉ |

**中黒「・」そのものを入力したい場合は、直前のかなをいったん確定してから押してください。**

### 「ぁ」「ぅ」「ぉ」を単体で入力する

同じ小さいかなのキーを2回押します。

| 入力するキー | 出力 |
| --- | --- |
| ゃ → ゃ | ぁ |
| ゅ → ゅ | ぅ |
| ょ → ょ | ぉ |

「うわぁぁぁぁぁぁ」のように、小さい母音を続けて入力したいときにも使えます。

## 導入方法

Google日本語入力をインストールし、ローマ字テーブルの設定から、この配列の定義ファイルをインポートします。

配布する定義ファイルは、次の3種類です。

| 種類 | 対象 |
| --- | --- |
| QWERTY用 | 一般的なQWERTY配列のキーボードを使う方向け |
| 大西配列用 | QMK などでキー配列を大西配列に変更している方向け |
| 洋かたなさら配列用 | QMK などでキー配列を洋かたなさら配列に変更している方向け (作者はこの版を使用しています) |

この3種類は、キーボード側の配列に合わせて選んでください。
その他の配列を使用している方はご自分で用意してください。

## 作成方法
この配列がどのように作られたかの情報を残しておきます。この配列をもとに改造して使う方やこの配列を使うか迷っている方の参考になれば幸いです。

作成に当たっては新下駄配列作者のkouy氏が公開している「100万字日本語かなn-gramデータ」を使用しました。

この配列は、かなの頻出順データと2連接データを参考に手組みした配列で、機械計算などは行っていません。実際のキーボードで押しやすいキーとアルペジオ打鍵を探して、そこに頻出順でかなをあてつつ、レイヤーキー込みで連接を考え悪い運指を排除して作りました。

シフトキーが多い配列のため悪い運指をマイナー外来音に押し付けて清音、濁音、半濁音は比較的打ちやすい位置に入れることができました。コンパクトな配列ということもあり、手のバタバタ感はかなり少ない配列になったと思います。

単打かなは小指や薬指までしっかりと使い、マイナーな清音、濁音は人差し指に集める形になりました。これはシフトキーが左右の中指、薬指にあるため連接を考慮すると人差し指で1打目を打つのが良いと考えたためです。拗音に繋がるかなのうち、メジャー拗音は小指、2軍拗音は人差し指内側に集める形になりました。これにより「しょう」や「きょう」などが打ちやすくなります。

ちなみにこの配列でもっとも押しにくい単体かなは「ぺ」になります。右手上段の小指と薬指のアルペジオではありますが小指を伸ばすのがきついので、もっとも使わなそうな「ぺ」になっています。

単打で入力する30かなは、ほぼ使用頻度順に選んでいます。単打率は7割弱です。配列図には単打を含めて6面ありますが、覚えるかなの割り当ては80文字分です。配置を工夫しているのでアルペジオ打鍵ごとに、かなが割り当てられているような感覚で使えます。

まとめると、親指を文字入力に使わないこと、30キーの格子配列に収まること、清濁別置き、拗音・外来音を同じ規則で入力できること、Google日本語入力で実装できることなどの要件をもとに「100万字日本語かなn-gramデータ」を見つつアルペジオ打鍵を重視して手組みで作った配列になります。

## 作成経緯
カスタムキーボードをきっかけにキーボードにはまってATC2024の動画で新配列を知りました。その後、ローマ字系配列や新下駄配列などを使いましたが、自分の求める条件の配列が無かったため一番理想に近かった「月見草エキス」をもとに自作することにしました。

私が新配列に求める条件としては、

・文字入力に親指を使用しない
自作キーボード勢がコンパクトなキーボードを使用する場合、親指は変換、確定の他にキーボード側のレイヤー移動にも使います。さらに文字入力の際にも親指でレイヤーを切り替えるのは親指の負荷が高すぎるので嫌でした。IME実装の配列ならスペース長押しをShiftキーに設定して大文字アルファベットをIMEオンのまま打てるので便利です。

・30キー範囲、オーソリニアを前提に作成されている。
今どきの自作キーボード勢は文字入力用途ならば、カラムスタッガードとオーソリニアが主流です。ロウスタッガードが主流の時代に作られた配列ではキーの使用頻度が左右対称ではなく違和感があります。また、かな配列に限ると30キーの範囲からはみ出しているものも多いです。

・清濁別置き
新下駄の経験から清音、濁音、半濁音は別置きでも十分覚えられると分かりましたし、連接の違いを考慮すると清濁別置きが良いと思いました。

・拗音、外来音をすべて同じ規則で打てる
新下駄をリタイアした一番の理由が拗音レイヤーが合わなかったことです。自分は「しょ」を「し」と「ょ」として認識しているため「しょ」を打とうとすると自然に「し」を打ってしまいます。なんならQWERTYでは「SIXYO」と打っていましたし、手書きでも「し」+「ょ」の認識です。そういう意味では「ゃゅょ」を単打で打てる月見草式のシフトは自分にとってぴったりでした。マイナー外来音をすべて考慮するかについては様々な意見があると思いますが、自分は同じ規則で打てない文字があるとモヤモヤするので入れる派です。

・Google日本語入力のみで実装可能
新下駄は紅皿で使っていましたが、やっぱりIME上で動いてほしいと思ったのでGoogle日本語入力で完結する月配列系が魅力的でした。月見草エキスをベースにしようと思ったのもここが大きいです。

これらの条件に合う配列を見つけられなかったので自作することにしました。
